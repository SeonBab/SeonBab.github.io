# 클럭

클럭(Clock)은 CPU 동작의 기준이 되는 시간 단위로, 이 신호에 맞춰 다음과같은 작업이 이루어집니다.

- 레지스터 간 데이터 이동
- ALU 연산 수행
- 메모리에서 명령어 읽기

단, 모든 부품이 클럭 신호에 맞춰 동작하지만, 모든 부품이 매 클럭마다 동작하는 것은 아닙니다.  
각 부품은 클럭에 동기화되어 필요할 때만 동작합니다.
