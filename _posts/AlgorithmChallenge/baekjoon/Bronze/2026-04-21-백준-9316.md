# Hello Judge

## 문제 링크

[Hello Judge](https://www.acmicpc.net/problem/9316){: target="_blank"}

## 분석

입력으로 정수 N이 주어집니다.

해당 정수만큼 "Hello World, Judge i!"를 출력하며 줄바꿈을 해주어야 합니다.  
여기서 `i`는 줄의 번호를 의미합니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n;
	
	cin >> n;

	for (int i = 1; i <= n; ++i)
	{
		cout << "Hello World, Judge " << i << "!" << endl;
	}

	return 0;
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
