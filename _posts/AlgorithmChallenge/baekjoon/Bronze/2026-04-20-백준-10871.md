# # X보다 작은 수

## 문제 링크

[# X보다 작은 수](https://www.acmicpc.net/problem/10871){: target="_blank"}

## 분석

입력으로 정수가 N개로 이루어진 수열과 정수 X가 주어집니다.

해당 수열에서 X보다 작은 값들을 찾아 출력하는 문제입니다.

수열은 반복문으로 순회하며, 작은 값들은 조건식으로 찾아내면 됩니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int N, X, a[10000];

	cin >> N >> X;

	for (int i = 0; i < N; i++)
	{
		cin >> a[i];

		if (X > a[i])
		{
			cout << a[i] << " ";
		}
	}
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 순회 $O(n)$

공간 복잡도는 $O(n)$입니다.

- 입력 값을 관리하는 배열 $O(n)$
