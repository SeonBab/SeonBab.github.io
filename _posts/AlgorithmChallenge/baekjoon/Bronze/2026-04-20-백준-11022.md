# A+B-8

## 문제 링크

[A+B-8](https://www.acmicpc.net/problem/11022){: target="_blank"}

## 분석

첫째 줄에 테스트 케이스의 개수가 주어집니다.  

각 테스트 케이스는 한 줄로 이루어져 있고, 정수 2개가 주어집니다.  
정수와 정수 사이는 공백으로 구분됩니다.

정수 2개의 합을 출력해주어야 하는데, 결과를 의미하는 정수 합만 출력하면 안되며 예시는 다음과 같습니다.  
Case #\*: \* + \* = \* 형식으로, 몇 번째 테스트 케이스인지와 더하는 수식과 결과를 함께 출력해주어야 합니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n, a, b;

	cin >> n;

	for (int i = 1; i <= n; ++i)
	{
		cin >> a >> b;

		cout << "Case #" << i << ": " << a << " + " << b << " = " << a + b << endl;
	}
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
