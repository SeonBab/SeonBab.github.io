# 기찍 N

## 문제 링크

[기찍 N](https://www.acmicpc.net/problem/2742){: target="_blank"}

## 분석

입력으로 $N$이 주어질 때, 한 줄에 하나씩 $N$부터 1까지 1씩 감소하는 값을 출력하는 문제입니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main(void)
{
	ios::sync_with_stdio(false);

	int N;

	cin >> N;

	for (int i = 1; N >= i; N--)
	{
		cout << N << "\n";
	}
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
