# A+B-4

## 문제 링크

[A+B-4](https://www.acmicpc.net/problem/10951){: target="_blank"}

## 분석

입력되는 테스트 케이스의 개수는 주어지지 않습니다.

입력되는 테스트 케이스 1개는 정수 A와 B로 이루어져있고, 두 정수의 합을 구해야합니다.

테스트 케이스의 개수는 주어지지 않기 때문에 입력 스트림을 확인하여 끝에 도달했는지 확인해야합니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int a, b;

	while (!(cin >> a >> b).eof())
	{
		cout << a + b << endl;
	}

	return 0;
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 입력이 유효하지 않을 때까지 입력받는 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
