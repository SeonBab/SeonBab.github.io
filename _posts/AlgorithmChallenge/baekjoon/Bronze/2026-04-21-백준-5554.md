# 심부름 가는 길

## 문제 링크

[심부름 가는 길](https://www.acmicpc.net/problem/5554){: target="_blank"}

## 분석

입력으로 한 줄에 하나씩 이동 시간을 의미하는 수로 초가 주어집니다.  
이렇게 총 4개의 값이 주어지며, 해당 값으로 분과 초를 구해 출력하는 문제입니다.

첫째 줄에는 분을 출력하고, 둘째 줄에는 초를 출력하면 됩니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int a, b, c, d, time;
	
	cin >> a >> b >> c >> d;

	time = a + b + c + d;

	cout << time / 60 << endl << time % 60;

	return 0;
}
```

## 성능 요약

시간 복잡도는 상수 시간에 끝나기 때문에 $O(1)$입니다.

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
