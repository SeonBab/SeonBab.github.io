# A+B-2

## 문제 링크

[A+B-2](https://www.acmicpc.net/problem/2558){: target="_blank"}

## 분석

첫 번째 줄과 두 번째 줄에 정수가 주어지며, 해당 정수들의 합을 출력하는 문제입니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main(void)
{
    int a, b;

    cin >> a >> b;

    cout << a + b;
}
```

## 성능 요약

시간 복잡도는 상수 시간에 끝나기 때문에 $O(1)$입니다.

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
