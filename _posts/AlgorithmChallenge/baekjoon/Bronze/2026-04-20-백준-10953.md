# A+B-6

## 문제 링크

[A+B-6](https://www.acmicpc.net/problem/10953){: target="_blank"}

## 분석

입력되는 테스트 케이스의 개수는 주어집니다.  
테스트 케이스의 입력은 한 줄로 이루어지며, 정수와 정수 사이에 쉼표(,)로 구분됩니다.

테스트 케이스에 주어지는 정수 A와 B의 합을 구해 출력해야합니다.

입력을 받을 때, 쉼표에 대한 처리를 해주기만 하면 쉽게 해결할 수 있는 문제입니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n, a, b;
	char comma;

	cin >> n;

	for (int i = 1; i <= n; ++i)
	{
		cin >> a >> comma >> b;

		cout << a + b << endl;
	}

	return 0;
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
