# 카드 게임

## 문제 링크

[카드 게임](https://www.acmicpc.net/problem/5522){: target="_blank"}

## 분석

입력으로 5번 정수가 주어질 때 총합을 출력하는 문제입니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n = 0;
	int sum = 0;
	
	for (int i = 0; i < 5; ++i)
	{
		cin >> n;

		sum += n;
	}

	cout << sum;

	return 0;
}
```

시간 복잡도는 상수 시간에 끝나기 때문에 $O(1)$입니다.
