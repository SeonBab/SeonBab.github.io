# 합

## 문제 링크

[합](https://www.acmicpc.net/problem/8393){: target="_blank"}

## 분석

`n`이 주어졌을 때, 1부터 `n`까지의 합을 구해 출력하면 됩니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n, total{};
	
	cin >> n;

	for (int i = 1; i <= n; i++)
	{
		total += i;
	}

	cout << total;
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 반복문 $O(n)$

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
