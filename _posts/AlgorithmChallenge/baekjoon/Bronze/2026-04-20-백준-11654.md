# # 아스키 코드

## 문제 링크

[아스키 코드](https://www.acmicpc.net/problem/11654){: target="_blank"}

## 분석

알파벳 소문자, 대문자, 숫자 0-9 중 하나만 입력으로 주어집니다.

해당 입력에 대한 아스키 코드에서 몇 번을 의미하는지 값을 출력하면 되는 문제입니다.

입력을 `char`형으로 받고, 출력할 때 `int`로 형변환하면 몇 번에 해당하는지 값을 구할 수 있습니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	char c;

	cin >> c;
	cout << (int)c;

	return 0;
}
```
