# R2

## 문제 링크

[R2](https://www.acmicpc.net/problem/3046){: target="_blank"}

## 분석

입력으로 R1, R1 + R2의 평균인 S가 주어질 때, R2의 값을 출력하는 문제입니다.

평균은 $S = \frac {R1 + R2}{2}$로 구할 수 있기 때문에, 이 식을 변형하여 $R2 = 2S - R1$으로 구할 수 있습니다.

## 풀이

```cpp
#include <iostream>

int main()
{
    int a, b;
    
    std::cin >> a >> b;
    
    std::cout << (b * 2) - a;
}
```
