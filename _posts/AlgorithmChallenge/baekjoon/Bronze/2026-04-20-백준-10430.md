# 나머지

## 문제 링크

[나머지](https://www.acmicpc.net/problem/10430){: target="_blank"}

## 분석

값 3개가 주어질 때, 해당 값을 이용해 나머지를 출력하는 문제입니다.

나머지를 구하는 연산자는 `%`이므로, 해당 연산자를 활용하면 쉽게 풀 수 있습니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
    int a, b, c;

    cin >> a >> b >> c;

    cout << (a + b) % c << "\n";
    cout << ((a % c) + (b % c)) % c << "\n";
    cout << (a * b) % c << "\n";
    cout << ((a % c) * (b % c)) % c << "\n";

}
```

## 성능 요약

공간 복잡도는 고정된 크기의 상수 공간을 사용하기 때문에 $O(1)$입니다.
