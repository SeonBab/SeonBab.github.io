# 문자열

## 문제 링크

[문자열](https://www.acmicpc.net/problem/9086){: target="_blank"}

## 분석

첫 입력으로 테스트 케이스의 개수가 주어집니다.  
각 테스트 케이스에는 문자열이 주어집니다.

테스트 케이스의 문자열이 가진 첫 글자와 마지막 글자를 출력하면 되는 문제입니다.

## 풀이

```cpp
#include <iostream>

using namespace std;

int main()
{
	int n;

	string s;

	cin >> n;

	for (int i = 0; i < n; ++i)
	{
		cin >> s;

		cout << s[0] << s[s.length() - 1] << endl;
	}

	return 0;
}
```

## 성능 요약

시간 복잡도는 $O(n)$입니다.

- 테스트 케이스를 순회하는 반복문 $O(n)$

공간 복잡도는 $O(l)$입니다.

- 문자열을 저장하는 `s` $O(l)$
	- 입력으로 주어지는 문자열의 최대 길이에 의해 $O(l)$이 됩니다.
