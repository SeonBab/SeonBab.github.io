# SeonBab's Devlog

## 사용 라이브러리

### Ruby Gems
- **jekyll**: 정적 사이트 생성기
- **jekyll-paginate**: 페이지네이션 플러그인
- **jekyll-sitemap**: 사이트맵 생성 플러그인
- **jekyll-gist**: GitHub Gist 임베딩 플러그인
- **jekyll-feed**: RSS 피드 생성 플러그인
- **jekyll-include-cache**: 인클루드 캐싱 플러그인
- **webrick**: Ruby 웹 서버
- **tzinfo**: 시간대 정보 라이브러리
- **tzinfo-data**: Windows용 시간대 데이터

### JavaScript/Node.js 패키지
- **npm-run-all**: 여러 npm 스크립트를 병렬/직렬로 실행
- **onchange**: 파일 변경 감지
- **uglify-js**: JavaScript 압축 도구
- **jQuery**: JavaScript 라이브러리 (버전 3.6.0)
- **jquery.fitvids**: 비디오 반응형 플러그인
- **jquery.greedy-navigation**: 탐욕스러운 네비게이션 플러그인
- **jquery.magnific-popup**: 팝업 플러그인
- **jquery.ba-throttle-debounce**: 스로틀/디바운스 플러그인
- **smooth-scroll**: 부드러운 스크롤 라이브러리
- **gumshoe**: 스크롤 스파이 라이브러리
